    THE SAME OPERATION, BEYOND A GAME
    A question becomes
    a Boolean expression.
    Each row represents one character. Each column describes one visible property. A “no” answer uses the complement of that column. Logical AND keeps only rows that satisfy every answer so far.
    The same idea filters data tables: records with a given category, measurements within a range, or pixels that match several conditions.
    Try a prediction
    Before asking, count the remaining 1s and 0s in a column. There are 32 = 2⁵ characters: every combination of five binary features appears once. Each new feature question halves the remaining candidates, so five answers identify one face.
    When one candidate remains, click that face to confirm your deduction. Can you solve a mystery with fewer questions next time?
