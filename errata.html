CORRECTIONS & FEEDBACK

Good questions.
Better explanations.

Found a mistake, a broken example, or an explanation that does not add up? Help make the materials clearer.

Report a problem

Search the repository’s Issues page first. To submit a report you need a GitHub account. Please include:

  • Book language, format, volume, and edition or printing.
  • Module, section heading, listing filename, and page number if available.
  • What you expected, what happened, and the complete error message.
  • For code: operating system, Python version, and library versions.

Remove personal paths and private information from screenshots and logs before posting.

View or report an issue ↗

Which version am I using?

Website labs are JavaScript learning models. The repository contains Python examples. Mention which one you are using: the simplified browser lab can differ from the full project.

The repository history records code changes. A newer repository file does not imply that a printed edition includes that revision.

Edition-specific corrections

This page will collect verified corrections by edition and listing. No post-publication errata list has been established here yet; this does not mean every edition is error-free.
