## Shared organization

- `steps/iteration_MM_NN_name.py`: runnable stages, in chapter order.
- `examples/example_MM_NN_name.py`: independent examples, numbered separately.
- `solutions/solution_MM_TT_name.py`: solutions, using the exercise number.
- `final/`: complete programs.
- `patches/iteration_MM_NN_to_KK.patch`: differences between consecutive steps.

Listing identifiers match filenames. They are not page numbers. Run files separately; do not concatenate them. Keep resource folders with the programs.
