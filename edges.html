LAB 08 · COMPUTER VISION

Find the edges
with subtraction.

An image is a matrix of brightness values. Where neighbouring pixels have the same value, their difference is zero. Where brightness changes, an edge appears.

01 / INPUT

Image

Click a pixel to toggle it. White is 1. Black is 0.

02 / DIFFERENCE

Compare neighbours

03 / OUTPUT

Edges

A cell lights up if either difference is 1.

Rows and columns start at 0, as in NumPy. The selected position is highlighted in all three matrices.

Apply the same operation across the image

Compare each pixel with its left and upper neighbours. The first column has no left neighbour and the first row has no upper neighbour, so those missing differences stay zero. The result marks brightness changes at the right or lower cell of each pair.

I = image.astype(np.int16)
dx = np.zeros_like(I)
dy = np.zeros_like(I)
dx[:, 1:] = np.abs(I[:, 1:] - I[:, :-1])
dy[1:, :] = np.abs(I[1:, :] - I[:-1, :])
edges = np.maximum(dx, dy)

Try the stripes and switch directions. A vertical stripe changes brightness from left to right, so it appears in the horizontal difference.

Why can a corner be missing?

In the Square pattern, inspect image[6, 6], just outside the bottom-right corner. This pixel and its left and upper neighbours are all 0, so both differences are 0. The white pixel is diagonal to it, and this rule does not compare diagonal neighbours. The result follows the chosen rule; a different definition of an outline would need a different rule.
