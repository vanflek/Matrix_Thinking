FROM THE BOOK

Build a view.

This JavaScript adaptation uses Module 22’s original 16 × 32 maze and starting cell (8, 16). It follows the same sample-based ray search, directions through strip centres, forward-depth correction, distance shading, and projected floor grid. Movement checks short steps on each axis before entering a passage.

Try a prediction

Pause and change the field of view. The maze and observer position stay unchanged; the ray directions, wall heights and image change. Reduce the ray count to see the image’s vertical strips.

Rays that leave the maze without finding a wall have no wall strip. The browser shows their status explicitly. All distances use the book’s world units: each cell is 30 units wide.

JavaScript runs in the browser; Python and NumPy are not executed. The learning interface adds ray selection and passage-cell positioning. There are no added enemies or victory rules.
