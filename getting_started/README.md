# Getting started — Matrix Thinking

Preparation before projects 0–23; project numbering is unchanged.

Use Python 3.13 (64-bit, Windows Intel/AMD). Create a project-specific `.venv` in PyCharm. Install the versions listed in `requirements.txt` into that environment. The book explains GUI installation and equivalent pip commands.

## Run in order

1. `hello.py` — prints a greeting, 5, and the text 2 + 3. Listing `example_setup_01`.
2. `check_libraries.py` — checks imports. Listing `example_setup_02`.
3. `check_window.py` — prints a 2×3 array and opens a blue 600×400 window. Close its X button to finish. Listing `example_setup_03`.

`sample_files/picture.png` is an original image made for this book. Copy it to an `images` folder in your practice project to rehearse file management; none of the scripts requires this image.

The deliberate errors printed in the troubleshooting section are exercises, not runnable project steps. Correct them before proceeding. Environment folders and IDE settings are not distributed.
