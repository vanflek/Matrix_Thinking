ПЕРВОЕ ЗАНЯТИЕ В MAKECODE: ОДИН ШАГ ДЛЯ ВСЕГО ПОЛЯ

Общая задача с MicroPython: предсказать и выполнить сдвиг матрицы 5×5 вниз
на одну строку. A — один шаг. B — исходное поле.

WORLD В БЛОКАХ
Создайте переменную world. Это список текстовых строк, а не список кадров:
  09000
  09900
  00000
  00000
  00000
Первая строка соответствует верхнему краю дисплея. Символ 9 обозначает
включённый светодиод, 0 — выключенный. Первый опыт двоичный: он не переносит
все градации яркости MicroPython в MakeCode. Его смысл — состояние и сдвиг.

ФУНКЦИЯ drawWorld
Создайте функцию без параметров. Два вложенных цикла от 0 до 4 перебирают
строку row и столбец col. Возьмите элемент world с индексом row, затем символ
этой строки с индексом col. Если это "9", включите светодиод (col,row);
иначе выключите его. Здесь цикл только выводит готовую матрицу на экран.

ПРИ ЗАПУСКЕ
Присвойте world исходный список из пяти строк. Вызовите drawWorld.

ПРИ НАЖАТИИ A
Присвойте world новый список из пяти элементов:
  "00000"
  элемент старого world с индексом 0
  элемент старого world с индексом 1
  элемент старого world с индексом 2
  элемент старого world с индексом 3
Затем вызовите drawWorld.
Вся правая часть вычисляется до присваивания: исходные строки читаются
из старого мира. Нижняя строка теряется; верхняя становится нулевой.
Отдельно обсудите ошибку последовательной перезаписи строк сверху вниз.

ПРИ НАЖАТИИ B
Снова создайте исходный список и вызовите drawWorld. Не сохраняйте world
ссылкой на другой изменяемый массив в качестве «независимой копии».

выберите Import → Import File и этот файл. Проект экспортирован штатной
командой Save the project после преобразования программы в Blocks.

Запасной путь через исходник:
Создайте проект в MakeCode, откройте JavaScript, вставьте содержимое
01_shift_world_makecode.ts, затем переключитесь на Blocks. JavaScript-режим
MakeCode использует TypeScript; .ts не предназначен для обычного браузерного
console или MicroPython. Все конструкции примера относятся к базовым блокам:
списки, текст, переменные, функции, циклы, условие, LED и события кнопок.

ПРОВЕРКА УЧЕНИКОМ
До A запишите следующую матрицу на бумаге. После двух A исходный рисунок
должен оказаться на строках 2 и 3 (с нуля). После пяти A поле пустое. B
полностью восстанавливает рисунок. Повторите прогноз в MicroPython.
Сравнивайте расположение включённых клеток: 9/0 — договорённость данных;
физический диапазон яркости API MakeCode отличается от MicroPython.
